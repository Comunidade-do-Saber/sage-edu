# Security Policy

## Supported Versions

SAGE Education is under active development. Security fixes are provided
for the latest released version of each module. We recommend always
running the most recent release.

| Version | Supported |
|---|---|
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub
issues.** Publicly disclosing a vulnerability before it is fixed can put
users and institutions running SAGE Education at risk.

If you believe you have found a security vulnerability in this project,
please report it privately so we have time to investigate and fix it
before it is made public.

### How to Report

1. **Email us directly:** suporte@comunidadedosaber.ao
2. **GitHub Security Advisories:** if this repository has Private
   Vulnerability Reporting enabled, use the `Security` tab →
   `Advisories` → `Report a vulnerability`.

Please include as much detail as possible: affected module and version,
steps to reproduce, and potential impact. This helps us respond faster.

### What to Expect

- We will acknowledge your report within a reasonable timeframe.
- We will keep you informed as we investigate and work on a fix.
- We will credit reporters who wish to be credited, once the issue is
  resolved and disclosed responsibly.

*As an open-source, community-driven project, we currently do not offer
financial bug bounties, but we deeply appreciate your contributions to
keeping SAGE Education and its users safe.*
